# Zayqa Digital Sanctuary

Build a production-quality restaurant website for a premium restaurant brand called:

ZAYQA LOUNGE

TAGLINE:

WHERE FLAVOUR MEETS ATMOSPHERE

IMPORTANT:

This is a premium restaurant. Do NOT make it look like a website-builder demo, SaaS dashboard, AI-generated website, futuristic concept, or feature showcase.

The goal is to make a real restaurant owner look at the website and think:

“My restaurant could look like this.”

The website must feel expensive, sophisticated, editorial, atmospheric, highly usable, and completely believable as a real restaurant website.

==================================================

1. CORE CREATIVE DIRECTION

==================================================

Design Zayqa Lounge as a high-end hospitality brand translated into digital form.

The visual experience should feel:

- Elegant

- Warm

- Sophisticated

- Editorial

- Atmospheric

- Contemporary

- Intimate

- Premium

- Confident

- Natural

- Timeless rather than trendy

Think:

Luxury restaurant + editorial food photography + refined hospitality + excellent UX.

DO NOT make it:

- Futuristic

- Cyberpunk

- AI-looking

- Overly technological

- Over-animated

- Glassmorphism-heavy

- Neon

- Generic template-like

- Overly minimal to the point of emptiness

- Filled with random decorative elements

The website should be visually impressive because of excellent composition, photography, typography, spacing, interaction design, motion and detail.

NOT because of gimmicks.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
